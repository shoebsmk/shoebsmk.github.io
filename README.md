# Shoeb Khan | Portfolio Website

A modern, interactive portfolio website showcasing my work as a Software Engineer and Mobile App Architect.

🔗 **Live Demo:** [shoebsmk.github.io](https://shoebsmk.github.io)

## ✨ Features

- **Interactive 3D Background** – Animated particle system built with Three.js
- **Smooth Animations** – Page transitions and scroll effects powered by GSAP
- **Responsive Design** – Optimized for all devices using Tailwind CSS
- **Contact Form** – Functional email integration with EmailJS
- **Fast Development** – Vite-powered build system with hot module replacement

## 🛠️ Tech Stack

| Category | Technologies |
|----------|-------------|
| **Build Tool** | [Vite](https://vitejs.dev/) |
| **Styling** | [Tailwind CSS](https://tailwindcss.com/), PostCSS, Autoprefixer |
| **3D Graphics** | [Three.js](https://threejs.org/) |
| **Animations** | [GSAP](https://greensock.com/gsap/) |
| **Email** | [EmailJS](https://www.emailjs.com/) |
| **Icons** | [Font Awesome](https://fontawesome.com/) |

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/shoebsmk/shoebsmk.github.io.git

# Navigate to the project
cd shoebsmk.github.io

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
npm run preview  # Preview production build locally
```
